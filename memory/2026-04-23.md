### Frontend App

| File | Changes |
|------|---------|
| `hooks/useWindowWidth.js` | New hook — listens to `resize` and returns `window.innerWidth`. Used to detect mobile breakpoint. |
| `Dashboard.jsx` | Imports `useWindowWidth`. `isMobile = width < 768`. Desktop: sidebar renders in flex layout as before. Mobile: sidebar is a fixed-position slide-in drawer (z-56), toggled by person icon button in nav. Backdrop with blur closes it on tap. Body scroll locked when open. Profile nudge on mobile has inline link to open profile. Main padding: `16px` on mobile, `28px 32px` on desktop. |
| `ProfilePanel.jsx` | Accepts optional `onClose` prop. When provided (mobile): renders a close bar at top with X button. `background: '#FAF7F2'` explicit (needed for overlay). |
| `ListingDetail.jsx` | Property stats grid: `repeat(auto-fit, minmax(100px, 1fr))` — naturally 2×2 on mobile (<640px content), 4-across on desktop. |

### Key decisions
- Mobile breakpoint: 768px (`< 768` = isMobile)
- Desktop sidebar stays in the flex layout (no layout shift)
- Mobile sidebar is fully outside the flex layout — rendered as a fixed overlay sibling
- ProfilePanel width: 280px on desktop (unchanged), `min(300px, 85vw)` on mobile
- `useWindowWidth` re-renders on resize — acceptable cost for responsive components
