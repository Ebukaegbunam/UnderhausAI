### Features

- **Left sidebar**: user avatar/name/email + investor profile form stored in localStorage
- **Profile fields**: annual income, down payment %, credit score, investment goal, monthly debt, target CoC %; advanced section (vacancy, mgmt fee, maintenance, capex)
- **Profile nudge banner**: yellow warning if profile not saved before searching
- **Search bar**: location input + radius, property type, min/max price dropdowns; Enter key triggers search
- **Search history**: pill buttons of past 10 searches, click to re-run; stored in localStorage
- **Loading state**: spinner + shimmer skeleton cards during API call
- **Results grid**: auto-fill columns, animated on load
- **ListingCard**: image, price, beds/baths/sqft, property type, days on market, verdict badge (GO/MAYBE/NO GO), cash flow/CoC/cap rate row
- **ListingDetail**: slide-up modal with full underwriting breakdown — all expense line items, DSCR, GRM, verdict reason, flags
- **ComingSoonModal**: "Deep Underwriting" button on each card and in detail sheet; shows a clean coming-soon popup
- **Sign out**: in nav, clears token and redirects to /login

### Profile field improvements (follow-up commit)

- Annual income: $10k increments up to $500k+
- Down payment: added Cash (100%) option — maps to 50% in backend payload (backend max is 50%)
- Credit score: numeric values by 10s (580–800+), mapped to backend credit_range enum at payload build time
- Min/max price: replaced text inputs with dropdowns ($50K–$2M+)
- Tooltips: hover ⓘ on every field with plain-English explanation

### Key decisions

- Investor profile stored in localStorage under `uh_profile` — no backend save endpoint yet
- Search history stored in localStorage under `uh_search_history` (last 10 searches)
- `credit_score` (numeric) stored in profile; `scoreToCreditRange()` maps to backend enum at search time
- Cash (100%) down payment maps to 50% in payload — backend doesn't model zero-mortgage deals yet
- Deep Underwriting button → "Coming Soon" modal — not connected to backend
