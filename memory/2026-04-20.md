## Authentication System (OAuth — Google + GitHub)

**What was built:**

| File | Purpose |
|------|---------|
| `db/models.py` | SQLAlchemy async models: `User`, `OAuthAccount`, `UserSession`. Unique constraint on `(provider, provider_user_id)`. Soft delete fields on User: `is_deleted`, `deleted_at`. |
| `db/session.py` | Async SQLAlchemy engine + sessionmaker. `init_db()` creates all tables on startup via lifespan hook. |
| `routes/auth.py` | OAuth routes: `GET /auth/{provider}/login` → redirects to provider, `GET /auth/{provider}/callback` → exchanges code, creates user/session, redirects to `{FRONTEND_URL}/auth/callback?token=<jwt>`. `POST /auth/logout` revokes current session. `GET /auth/me` returns current user. `DELETE /auth/me` soft-deletes account + revokes all sessions. |
| `services/auth_service.py` | `create_access_token()` returns `(token, jti)`. `get_or_create_user()` checks OAuth account first, then email match, then creates new user. `soft_delete_user()` marks `is_deleted=True`, sets `deleted_at`, revokes all `UserSession` rows. |
| `dependencies/auth.py` | `require_user`, `require_admin`, `optional_user` FastAPI dependencies. Read JWT from `Authorization: Bearer <token>` header, validate jti against `UserSession` table. Admin check via `user.role == "admin"`. |

**Key decisions:**
- Google and GitHub only — no email/password auth
- GitHub: calls `/user/emails` to get verified primary email if not public
- JWTs are stateful for revocation: each token has a `jti`, stored in `UserSession`. Logout deletes the session row.
- Soft delete: user row stays, `is_deleted=True` + `deleted_at` set. Existing data (future: search history, saved listings) is preserved. Login attempts by a deleted user return 403.
- `SessionMiddleware` (Starlette/itsdangerous) added to `main.py` for authlib OAuth state storage — requires `SESSION_SECRET` env var.
- OAuth providers configured in `routes/auth.py` using `authlib.integrations.starlette_client`.
- Redirect after OAuth: `{FRONTEND_URL}/auth/callback?token=<jwt>` — frontend reads the token from query param and stores it.

**Env vars needed (in `.env`):**
```
JWT_SECRET=<generate: python3 -c "import secrets; print(secrets.token_hex(32))">
SESSION_SECRET=<generate same way>
GOOGLE_CLIENT_ID=<from Google Cloud Console>
GOOGLE_CLIENT_SECRET=<from Google Cloud Console>
GITHUB_CLIENT_ID=<from github.com/settings/developers>
GITHUB_CLIENT_SECRET=<from github.com/settings/developers>
FRONTEND_URL=http://localhost:5173
API_BASE_URL=http://localhost:8001
```

**OAuth callback URLs to register:**

- GitHub: `http://localhost:8001/auth/github/callback`
